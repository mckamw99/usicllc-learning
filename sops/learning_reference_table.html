Overview

TDMs review and update every row for the districts they support, so that enrollment, reporting and 2027 instructor planning use correct values. Each row takes about 5 minutes.

This review roundOpen the list, update every field for each of your districts using the Field guide, run the Quality checklist, set Last Reviewed to today, and save. Complete it by the date in the request from L&D Operations.

Why it matters

One wrong number in a row flows into enrollment, dashboards and headcount planning without anyone noticing.

The table is not connected to Docebo. Changing a district’s utilities here does not change Docebo enrollments. L&D Operations makes that change by hand, and it does not undo past enrollments.

Before you start

Have these on hand so every row is filled from facts, not memory.

  • Access: edit rights to the Learning Reference Table list. If the row opens read-only, ask Learning Analytics & Technology.
  • Your district list: every cost center you support, including districts you share instructors with.
  • Current class plan: your district’s cadence (weeks between class starts) and the date the current cadence started.
  • Program design: how many Utility Days, how many OJT days, and whether the instructor stays through OJT.
  • Utility mix: which utilities your learners locate (confirm with the Area Manager if unsure).
  • People: current Area Manager, Assistant Area Managers, HR partner, and TDM.
  • Certification rules: when learners become eligible for HP & Commercial and Telecom Vault, the share who need TCV, and whether Gas OQ applies.

Procedure

  1. 1
    Open the list.Go to the Learning Analytics and Technology site and open Learning Reference Table.
  2. 2
    Filter to your rows.Use the filter on Region, Division or L&D Manager, or search for your district abbreviation. Confirm every district you support appears; tell Learning Analytics & Technology if one is missing or listed under the wrong region or manager.
  3. 3
    Open a row.Double-click the row. A panel opens with every field for that district.
  4. 4
    Work top to bottom through the panel.Use the Field guide below. Identity and people fields: confirm or correct. Program fields: enter numbers only, in workdays. Certification fields: fill every one, entering 0 rather than leaving a number blank. Utilities: tick each utility learners must be trained on.
  5. 5
    Run the quality checklist(below) on the row before saving.
  6. 6
    Set Last Reviewedto today’s date, even if nothing changed.
  7. 7
    Click Saveat the bottom of the panel.
  8. 8
    Check the list view.Confirm the new values show in the row.
  9. 9
    Repeatfor each district you support.
  10. 10
    Tell L&D Operationsif you changed utilities, so Docebo can be updated by hand.

Rules that tie fields together

The program fields must add up; if one changes, check the others in the same row.

1. The workday timeline

Every district follows the same order, so the numbers chain together.

StageWorkdays (example: 10 Utility Days, 10 OJT)Formula
Foundations1–5Always 5 days
Utility Days6–155 + Utility Day Duration
OJT16–255 + Utility Day Duration + OJT Length
Nesting starts265 + Utility Day Duration + OJT Length + 1
HP & Commercial (811 only)40 (most districts)HPC Eligibility Period, in workdays from the first day; TCV right after HP

Reconn (AGO) learners finish after OJT; they do not go on to nesting or HP & Commercial.

2. Start to Cert decides how long an instructor is tied to a class

  • No: the instructor is tied up for Foundations + Utility Days, then free for other classes or certification sessions.
  • Yes: the instructor is tied up through OJT, or for the full cadence if the cadence is longer (a class every 6 weeks ties the instructor up for 6 weeks).
  • So a wrong Start to Cert answer, or a wrong cadence in a Start to Cert district, changes instructor forecasts the most.

3. Cadence and instructors must fit

In a Start to Cert district, if OJT ends after the next class starts, the classes overlap and need two instructors. Example: a 3-week cadence with 25 workdays of instruction needs at least 2 on Trainers Supporting District.

4. Sharing must match on both sides

If SCO lists NCO as a shared district, NCO must list SCO, with the same Sharing Type on both rows.

5. Utilities and OQ must agree

If Gas is ticked, Gas OQ Required is normally Yes and OQ Length is above 0. If Gas OQ Required is No, OQ Length is 0.

6. HP & Commercial comes after nesting starts

HPC Eligibility Period counts workdays from the employee’s first day, so it must be larger than Nesting Starting Workday. Most districts use 40, about 15 workdays (3 weeks) into nesting.
