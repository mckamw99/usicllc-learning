Exporting Question Responses Before Archiving

How to download each learner’s answers from the Columbia Gas Monthly Assessment test (course 3401) so the monthly results survive when the course enrollments are archived and reissued.

01

Why This Matters

Each month the course is reset by archiving every enrollment and enrolling the population again. Archiving keeps the course-level record for each learner: status, completion date and final score. It does not keep the test’s answer tracking. Once enrollments are archived, the question-by-question grid only shows attempts from the new cycle.

Warning: If you archive first, the question responses for that month can’t be pulled from the Docebo reports. This happened with the Aug 25 – Sep 30 cycle, archived Oct 1, 2026. Its scores were preserved, but its question responses were not.
02

When to Run It

Run the export immediately before you archive enrollments for the month, after the completion window has closed. Running it any earlier misses late completers.

Key note: Run it at the end of every cycle, even if completions are low. Each export is the only lasting record of that month’s question responses.

Export Procedure

  1. 1
    Open the courseFrom the admin menu, open Courses, search for Columbia Gas Monthly Assessment (course ID 3401) and open it.
  2. 2
    Note the Completed countSelect the Reports tab. The Course report shows the Enrolled, To Begin, In progress and Completed counts. Write down the Completed count because you’ll use it in section 05.
  3. 3
    Open Training material statisticsUnder the chart, select Training material statistics. The test appears as Test – Columbia Gas Monthly Assessment Questions with its average score.
  4. 4
    Open the testClick the underlined test title Columbia Gas Monthly Assessment Questions. A panel opens with the question list across the top and one row per learner below.
  5. 5
    Keep every question selectedLeave every question checkbox selected. The test draws from a pool of 53 questions, and only the selected questions become columns in the export.
  6. 6
    Export 1 – final attemptsLeave Last attempts only checked. Next to Export as, choose Excel and download the file.
  7. 7
    Export 2 – all attemptsUncheck Last attempts only and wait for the grid to refresh. Each failed retake now appears as its own row. Export to Excel again.
  8. 8
    Rename and save both filesRename both files using this pattern and save them to the team’s Columbia Gas assessment folder on SharePoint:
    3401_ColumbiaGas_Responses_2026-10_final.xlsx
    3401_ColumbiaGas_Responses_2026-10_all-attempts.xlsx
Confirm on first run: On the first run, check whether the export downloads right away or arrives later as a notification or email, and update this step to match. TBV The SharePoint folder location also needs to be agreed with LAT. TBV

What’s in the File

ColumnWhat it contains
UsernameEmployee ID login, e.g. 184054@usicllc.com
First name · Last nameLearner name
Completion DateDate and time the attempt was submitted
ScoreAttempt score out of 100, e.g. 80/100
Passed or failedMeasured against the pass mark of 80
One column per questionThe answer text the learner chose. A blank cell means that question wasn’t drawn for that learner’s attempt.
Key note: The grid shows the answers learners chose, not whether each one was right. To score individual questions, compare the answers with the answer key in the test (Training material → the test → edit questions). Multi-select questions can give partial credit, which is why some scores land on values like 83.4 or 96.7.
05

Verify, Then Archive

  1. 1
    Check the row countOpen the final attempts file. Check that its learner row count matches the Completed count you wrote down in step 2. Learners who started the test but never submitted it won’t appear.
  2. 2
    Spot-check two learnersTheir score and completion date should match the User statistics grid on the Reports tab.
  3. 3
    Check the question columnsCheck that the question columns have answer text in them. If every question column is empty, a question filter was probably cleared, so re-export.
  4. 4
    Archive and reissueOnce both files are saved and checked, archive the enrollments and reissue the course as usual.
Recommendation: Drop a one-line note in the LAT channel with the month, completed count and file links. That makes it easy to find a month’s data later without searching SharePoint.

Recommended Long-Term Setup

The export works, but it depends on someone remembering a manual step every month. A sturdier pattern is to create a new course each month instead of archiving and re-enrolling. Duplicate course 3401 as, for example, Columbia Gas Monthly Assessment – Nov 2026, then enroll the population in the copy.

Question responses keptOnly if exported before archivingKept in each month’s course

Recommendation: Talk to LAT before switching. Enrollment rules, notifications and any learning plan that points to course 3401 would need to point to the new monthly course instead.
07

Troubleshooting

The grid only shows this month’s learners

That’s expected. The question grid only shows active enrollments. You can still see archived scores under Reports → User statistics → Enrollment status: Archived enrollments, but their question responses aren’t available there.

I already archived without exporting

Scores and completion dates are still available from the archived enrollments, so LAT can produce a completion and score report. Question responses for that cycle can’t be recovered through the admin reports. If they’re needed, LAT can ask Docebo support whether they can be restored. TBV

A learner shows Completed with a score of 0

Flag it to LAT before archiving. One September record (completed Sep 30, 2026) shows this pattern, and it should be checked against the test attempt.
