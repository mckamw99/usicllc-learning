Archiving a Course or Learning Plan

How USIC Academy retires outdated training in Docebo without losing completion history, certification records, or reporting access.

01

Purpose and Scope

Docebo's course archive removes a course from every learner-facing page while keeping its enrollments, completion records, and transactions. It is a one-way action: an archived course cannot be restored to active. This SOP standardizes when we archive, who approves it, what we export first, and the order of operations when learning plans are involved.

It covers four related actions: archiving a course, archiving course enrollments, retiring a learning plan, and archiving learning plan enrollments. Docebo has no native "archive" for a learning plan itself, so section 7 defines the USIC retirement procedure.

Key note: Only Superadmins can archive a course. Power Users, including Content Creators (profile 146912) and Learning Managers (146911), cannot. Power Users submit a request; LAT executes. Before submitting a course archive request, the Content Creator updates the course code to the ARC- format and unpublishes the course (section 6A).
02

Choose the Right Action

Most requests to "archive" something are really one of these four. Confirm which one the requester means before you touch anything.

Archive a course

The course is obsolete or replaced. Nobody should take it again. Permanent.

Archive course enrollments

The course stays live, but learners need a fresh attempt (annual retraining, monthly assessments). Course is not archived.

Retire a learning plan

The program is obsolete. The plan is unpublished and hidden; its courses may then be archived.

Archive LP enrollments

The plan stays live, but learners' plan progress is reset or closed out. Plan and courses remain.

Recommendation: If the course is being revised rather than retired, build the new version first, publish it, then archive the old one. Learners should never land in a gap where neither version is available.

04

What Course Archiving Does

Per Docebo's Archiving courses article (updated August 2026), once a course is archived:

  • It cannot be restored as an active course.
  • All active enrollments are archived in their current status and frozen at that moment.
  • Learners lose access to the course but can still see their progress and certificates on My activities.
  • It is removed from catalogs, enrollment rules, groups, and course equivalencies, and can't be added to new configurations.
  • For ILT courses, all past, present, and future sessions and events are canceled.
  • It is removed from every Power User's assigned resources, so Power Users can no longer see, track, or report on it.
  • It moves to the Archived tab of the Courses page.
Warning: certification records are deleted. Archiving permanently removes every certification record tied to the course. If the course awards a certification, export the certification report before archiving. There is no way to recover these records afterward.
Warning: blocked by dependencies. A course can't be archived while it is in any learning plan or linked to an automatic group. Check dependencies first (section 6B, step 4).
Warning: Outlook cancellations for past ILT sessions. If the Docebo Connect Outlook Calendar RSVP integration is enabled on an ILT course, archiving sends cancellation notices for past sessions too, and they can't be suppressed. Confirm whether the integration is active on the course TBV and warn instructors if so.

Pre-archive Checklist

06

Archive a Course

6A. Prepare the Course (Content Creator)

Before submitting the archive request, the Content Creator makes two changes. The ARC- course code makes archived courses easy to spot in reports, exports, and the Archived tab. Unpublishing stops learners from starting the course while the request waits for LAT.

FormatRuleExample
Course has a codeARC- + existing course codeULE-104 → ARC-ULE-104
Course has no codeARC- + Docebo course IDCourse ID 1801 → ARC-1801
  1. 1
    Go to Content and delivery (folder icon) > Courses and open the course.
  2. 2
    Open the Properties tab and find the Course code field.
  3. 3
    Add ARC- to the front of the existing code. If the field is blank, enter ARC- followed by the course ID. Use uppercase, with no spaces.
  4. 4
    Select Save changes, then confirm the new code shows on the Courses list.
  5. 5
    Unpublish the course: on the Courses list, select the ellipsis menu at the end of its row and choose Unpublish TBV. Confirm the status shows as unpublished.
  6. 6
    Submit the archive request through the LAT Zendesk intake. Include the new ARC- code and note that the course is unpublished.
Warning: unpublishing cuts off learners right away. Enrolled learners can no longer open an unpublished course. Before you unpublish, make sure the replacement course is published, no one still needs to finish this one, and, for a Mandatory or certification-bearing course, L&D Operations has approved the archive. For ILT courses, don't unpublish while sessions are still scheduled.
Warning: do this before you submit the request. After LAT archives the course, it disappears from the Content Creator's resources and the code can't be changed. If the request has already gone in, ask LAT to hold the archive until the code is updated.
Key note: Changing the code doesn't change the course ID, enrollments, or completion history. Check first whether any report, dashboard, or integration filters on this course's code, and tell the reporting stakeholders about the new code TBV.

6B. Archive the Course (LAT Superadmin)

  1. 1
    Sign in as a Superadmin and go to Content and delivery (folder icon) > Courses.
  2. 2
    Find the course and confirm its code starts with ARC- and that it is unpublished. If either is missing, return the ticket to the Content Creator, or make the change yourself using section 6A and note it in the ticket.
  3. 3
    Find the course, then select the ellipsis menu at the end of its row and choose Archive. The Archive course pop-up opens.
  4. 4
    Select Check dependencies. If any learning plan or automatic group is listed, open it from the right panel and remove the course, then return to this step. If the plan itself is obsolete, stop and follow section 7 first.
  5. 5
    Leave Upload the training material to the Training material page selected. This copies the course materials into a dedicated folder. Turning it off permanently deletes the materials.
  6. 6
    Select Archive now. The archive runs as a background job.
  7. 7
    Open the Archived tab, find the course, and confirm it appears. Open Enrollments to check that the frozen enrollment count matches your export.
Recommendation: Along with the ARC- code, prefix the course name with ARCHIVED – and the year (for example, ARCHIVED 2026 – Locate Basics v2). The archived snapshot keeps the name, which makes historical reports easier to read.
07

Retire a Learning Plan

Docebo does not archive learning plans themselves. Retiring a plan means closing out enrollments, hiding the plan, and then archiving its courses. Order matters: learning plan enrollments can't be archived once the plan has no courses left in it.

  1. 1
    Export the learning plan enrollment report and save it with the course exports.
  2. 2
    For each course in the plan, check whether it also belongs to another active plan. Shared courses stay live; only courses unique to this plan get archived.
  3. 3
    If learners' plan progress should be closed out, go to Content and delivery > Learning plans, open the plan, select the Enrollments tab, select the users, then Choose action > Archive enrollments. Do this while the courses are still in the plan.
  4. 4
    Remove the plan from all catalogs and enrollment rules so no one new is enrolled.
  5. 5
    Rename the plan with the ARCHIVED prefix and year, and set it to unpublished (or Under maintenance if your view offers it) TBV.
  6. 6
    Remove the courses that are unique to this plan, then update each code per section 6A, then archive it per section 6B.
Warning: adding or removing courses on a live plan. Adding a course to a published plan auto-enrolls all current members immediately. Confirm the plan is unpublished before editing its course list. The effect of removing a course from a plan on existing course enrollments should be confirmed in a test plan first TBV.
Key note: Docebo's new certifications and learning plan model (released late summer 2026) may change these options. Re-check this section against the tenant before each plan retirement TBV.
08

Bulk Archiving

Use bulk archiving for catalog cleanups. Every course in the batch must pass the pre-archive checklist individually, including its ARC- course code and unpublished status.

  1. 1
    On the Courses page, search for ARC- to list the courses waiting for archive, then select the checkboxes for up to 20 of them.
  2. 2
    Select Choose action in the bottom-right corner, then Archive.
  3. 3
    Complete the pop-up as in section 6B, steps 4 through 6. Any course with dependencies will block; remove it from the batch or clear the dependency.
  4. 4
    Check the background job result, then confirm each course on the Archived tab.
Key note: Archiving enrollments alone (without archiving the course) can also be scripted through the API using the existing dry-run, typed-confirmation, and audit CSV conventions. Course-level archive through the API is not yet confirmed TBV.
09

After Archiving

  • Close the Zendesk ticket with the archive date, export file locations, and anything not preserved (such as observation checklists).
  • Update the course governance lifecycle record in Confluence and any SOP, job aid, or QR code that linked to the course.
  • Notify the requester and reporting stakeholders that the course is archived and where the exported history lives.
  • Leave archived courses in place. The archived course's ellipsis menu offers View details, Check usage (catalogs, channels, and certificate templates at the time of archiving), and Delete.
Warning: don't delete archived courses. Delete on an archived course permanently erases all its data everywhere in the platform. Deletion requires a separate approval from L&D leadership.

Troubleshooting

ProblemCause and fix
Archive is blockedThe course is in a learning plan or an automatic group. Use Check dependencies, remove the course, and try again.
Can't archive a course's enrollmentsUsers completed it through a learning plan. Archive the learning plan enrollments instead, or retire the plan per section 7.
LP enrollment archive fails for some usersThe user is inactive. Reactivate, archive, then deactivate again (the standard inactive-user cycle).
"Archive and unenroll" does nothingA course in the plan also belongs to another plan. Docebo won't proceed in that case; resolve the overlap first.
LP enrollment archive is unavailableThe plan has no courses left. Archive LP enrollments before removing courses.
Content Creator can't unpublishThe Content Creator profile may not hold the publish/unpublish permission. Note it in the ticket and LAT unpublishes the course as part of section 6B.
Content Creator can't change the codeThe course is already archived and has left their resources. LAT updates the record in the ticket log; the archived snapshot keeps the old code.
Power User can't find historyExpected: archived courses leave all Power User resources. Send them the saved export.
11

Do's and Don'ts

Do
  • Update the course code to ARC- and unpublish the course before requesting an archive.
  • Export enrollments and certifications before every archive.
  • Publish the replacement first.
  • Keep training material upload selected.
  • Archive LP enrollments before removing courses from the plan.
  • Log every archive in the ticket.
Don’t
  • Archive a course whose code doesn't start with ARC- or that is still published.
  • Unpublish a course before its replacement is live.
  • Archive a Mandatory course without L&D Operations approval.
  • Archive to "reset" learners. Archive their enrollments instead.
  • Edit a published plan's course list.
  • Delete an archived course.
  • Archive an ILT course with sessions learners still need.
