Profile Summaries

Learning Management

Profile ID 146911

Regional delivery operations. The enrollment powerhouse — create, edit, archive, activate, learner-only restriction, and learning-plan enrollment management. Full ILT session set including enrollment edits. Reports edit. Sole holder of Insights custom dashboard creation. View-only elsewhere. Sees invisible user fields. Per Docebo docs, Reports/Edit + Courses/View also allows editing training-material progress and evaluating assignments from the Training material statistics area.

Program Manager

Profile ID 146910

Broad edit-level management — course edit and evaluation, learning plan create/edit, enrollment create/edit/activate, manual groups, certificate edit, notification edit, checklists, reports edit, external training edit, training material library edit. Sole holder of Locations edit. View-only on catalogs, Channels, Insights, and menus. No image management, no Pages, no invisible-field access. Full assignment evaluation (Evaluation + Reports/Edit).

Content Creator

Profile ID 146912

The sole creator role — courses, catalogs, channels, notifications, pages, menus, and training materials (including folder management), plus image management and gamification badge management. Learning plan create/edit (shared with PM). Enrollment is create-only. Reports view-only: CC can set final course scores but cannot evaluate assignments (requires Reports/Edit). Sees invisible user fields.

Compliance / Auditing

Profile ID 127639

Read-only oversight across catalogs, certificates, sessions, courses, enrollments, Insights, and learning plans, plus Reports edit and invisible-field access for audit purposes. No create, edit, or activate rights anywhere else. Cannot assign users to learning plans (LP View grants no enrollment management per Docebo docs).

Instructor

Profile ID 146178

Own-session ILT delivery — create/edit sessions, enroll learners, edit session enrollments. Enrollment create/archive/activate (learner-only), no enrollment edit. Course Edit on assigned courses (see Open Items). Sole holder of Admin Dashboard view. Sees invisible user fields.

Insights Viewer

Profile ID 136239

Analytics-only — three permissions total: Courses View, Insights View, Users View.

Key Findings & Open Items

  • RESOLVEDCompliance is fully read-only on enrollment (previous matrix showed Create/Activate in error).
  • RESOLVEDNo profile holds Manager Power Users — Power User administration is Superadmin-only. Docebo docs confirm the module only exists when enabled in Advanced settings; the toggle is off (deliberate hardening).
  • RESOLVEDCC evaluation scope: Courses/Evaluation alone permits setting final course scores and read-only assignment viewing; evaluating assignments requires Reports/Edit, which CC lacks. CC = final scores only; escalate to PM (full evaluation) or LM (material-progress edits via Reports/Edit + Courses/View).
  • RESOLVEDLP View grants no enrollment management: it shows only the course list; managing enrolled users requires Enrollment/Manage LP enrollments. Compliance cannot assign users to learning plans.
  • CONFIRMEDAll deletion is Superadmin-only, with the two documented self-created-content Create bundles noted above [TBV]. Treat as standing platform policy in any future profile change.
  • CONFIRMEDManage LP enrollments (PM/LM/CC/Instructor) includes enroll, unenroll, validity, marking complete, and recalculation at LP level — broader than course-level enrollment Edit (LM/PM only). LP enrollment auto-enrolls users into member courses.
  • OPENInstructor holds Courses Edit on assigned courses, including training materials — decide whether to bless (document in Instructor SOP) or revoke (Action A2).
  • OPENInvisible-field visibility on CC, LM, Instructor, and Compliance (not PM/Insights). The exposure surface is reports and the User Personal Summary. Document the decision or revoke (Action A3).
  • OPENEnrollment model: course-level Edit is LM/PM only; Archive sits on LM and Instructor; CC is create-only. LM and Instructor SOP enrollment sections require updates (Action A4).
  • OPENNewsletter/View is defined by Docebo as "Can send newsletters" — PM and CC can send. Confirm intended (Action A10).
  • TBVCourses/Waiting subscription and issued-certificate-only scoping are nested sub-permissions not visible on summary screens (Action A8).
  • TBVOwn-session delete bundle (Instructor test session, Action A7) and CC self-created unpublished page/menu delete (Action A11).

Module Descriptions

ModuleDescription
UsersManages user accounts: viewing, creating, editing, deleting users, user fields, activation, impersonation, and exporting user lists. Tenant profiles hold View only (plus invisible-field visibility on four profiles). View includes CSV/XLS export and the User Personal Summary.
GroupsOrganizes users into groups for management and assignment. Manual vs. automatic group distinctions apply; only manual groups can be created/edited by Power Users. Groups/View is required to select groups when enrolling.
CoursesCourse creation, viewing, editing, deletion, learner evaluation, waiting lists, training materials, and Question Bank access (via create/edit). Evaluation = set final course scores; assignment evaluation additionally requires Reports/Edit.
Learning PlansStructured learning paths grouping courses. View shows the course list only; enrollment management requires Enrollment/Manage LP enrollments. Note: adding a course to a published learning plan auto-enrolls all current members immediately.
EnrollmentEnrolling users into courses and learning plans: view, create, edit, archive, activation, and learner-only restriction. Enrollment permissions also apply to the Power User's own account.
Course CatalogsOrganizes courses into catalogs for browsing and assignment: view, create, edit, delete.
CertificatesCertificates for course and learning plan completion: viewing, editing templates, and assignment, with optional issued-only scoping.
NotificationsSystem notifications for assigned resources: view, create, edit, delete. Power Users see only notifications whose trigger filters match their resource assignments.
ILT SessionsInstructor-led training sessions: view, create, edit, session enrollment, and enrollment edits. Create bundles edit/enroll/delete for own-created sessions [TBV in tenant]; no profile holds the separate session Delete permission. Enroll users requires Enrollment View + Edit to work fully.
LocationsPhysical and virtual training locations: viewing and editing assigned locations.
Observation ChecklistsCreation and management of checklists; requires Users/View to create. Does not include checklist notifications.
ReportsAnalytics and reporting: viewing and editing custom reports scoped to visibility rules. Edit + Courses/View also permits editing training-material progress and evaluating assignments from Training material statistics.
NewsletterNewsletter/View is a send right: "Can send newsletters."
External TrainingTracking training completed outside the platform: viewing and editing records for assigned users, including CSV import and (if enabled) approval of user-reported activities.
DashboardAdministrative overview dashboard scoped to assigned users and courses.
Learning ImpactConsolidated reports and results comparison on learning program effectiveness, scoped to visible users.
Image ManagementCourse thumbnails and images: managing and selecting images.
GamificationBadges: manually assign/unassign to managed users; cannot edit badge details or automatic rules.
Training Material Library (Central Repository)Stores and manages training materials including documents, images, and AI lessons: view, create, edit, delete, folder management. Material permissions include access to the Creator tool.
InsightsAnalytics dashboards: viewing ready-to-use and shared dashboards and creating custom dashboards. Featured dashboards cannot be edited or deleted.
ChannelsContent channels (custom channels only can be assigned as resource): viewing and creating/managing channels; content management limited to courses and learning plans, not informal assets.
PagesContent pages: view, create, edit, publish/unpublish, and management of widgets and page assignments. Create and manage includes edit/delete of self-created unpublished pages.
MenusNavigation menus: view, create, edit, publish/unpublish, and management of menu assignments and visibility. Create and manage includes edit/delete of self-created unpublished menus.
